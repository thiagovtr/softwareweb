# Visão Geral do Produto

## Descrição do Problema
Os estudantes enfrentam muita dificuldade para encontrar, organizar e compartilhar materiais de estudo, como resumos de matérias, listas de exercícios e slides. 

Atualmente, esses conteúdos costumam ser compartilhados em grupos de mensagens e redes sociais, o que gera desorganização, perda de arquivos importantes e dificuldade de acesso rápido aos materiais necessários para estudo.

A ausência de um ambiente centralizado para armazenamento e compartilhamento acadêmico prejudica a colaboração entre estudantes e dificulta a preparação para avaliações e atividades universitárias.

## Visão do Produto
Desenvolver uma aplicação web que funcione como uma biblioteca digital acadêmica para estudantes da universidade.

O sistema permitirá que os usuários possam enviar, pesquisar, visualizar e baixar materiais acadêmicos de forma organizada por disciplinas, garantindo maior acessibilidade, organização e colaboração entre os alunos.

A plataforma buscará centralizar os conteúdos acadêmicos em um único ambiente, tornando o processo de estudo mais eficiente e facilitando o compartilhamento de conhecimento entre estudantes.

## Objetivos do Projeto
* Desenvolver um sistema web para upload, visualização e download de materiais acadêmicos.
* Organizar os conteúdos compartilhados por disciplinas, facilitando a busca e o acesso aos arquivos.
* Permitir o compartilhamento colaborativo de materiais entre estudantes.
* Garantir maior organização e acessibilidade aos conteúdos acadêmicos.
* Implementar autenticação de usuários utilizando e-mail institucional da universidade.
* Proporcionar uma interface simples, intuitiva e acessível para os usuários.
